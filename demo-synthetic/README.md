# Independently authored IDUN demonstration data

These four CSV/TXT files were written from scratch for a fictional software demonstration. They contain no real people, no MIMIC records or adapted MIMIC narrative, and no row-to-sentence annotation inputs. The examples are deliberately small and explicit; they illustrate interactions rather than benchmark clinical accuracy. Medication details are fictional example fields, not medical guidance.

Import the four raw files manually as a single lake. Their filenames and storage order do not define associations. Run the actual profiling, LOKI and LLM integration pipeline to produce the saved showcase; do not hand-label output tables.
